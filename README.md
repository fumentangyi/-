## 系统架构特点

### 🏛️ 三省六部制架构
- **中书省**：决策规划，制定执行方案
- **门下省**：审核校验，确保方案可行
- **尚书省**：执行调度，统筹六部工作
- **六部**：具体执行（吏、户、礼、兵、刑、工）

### 🔄 完整闭环流程
1. **决策阶段**：中书省制定方案
2. **搜索阶段**：联网搜索获取外部信息
3. **审核阶段**：门下省审核把关
4. **执行阶段**：尚书省调度六部
5. **反思阶段**：系统自我评估改进

### 🌐 联网搜索功能
系统具备智能联网搜索能力：
- 🤖 **智能判断**：自动分析任务是否需要外部信息
- 🔍 **多源搜索**：使用DuckDuckGo等搜索引擎获取信息
- 📊 **结果整合**：将搜索结果整合到决策过程中
- 🛡️ **容错处理**：网络异常时提供备用方案

### 🤖 反思机制
系统执行完成后，会自动进行反思分析：
- 📊 执行效率分析
- 🎯 结果质量评估  
- 💡 系统优化建议
- ⚠️ 潜在风险识别

确保在虚拟环境中：

应该看到：

```powershell

```

如果看到AI回复，说明环境正常。

## 架构说明

### 顶层三省
- **中书省**：决策规划 - 拆解任务、制定方案
- **门下省**：审核校验 - 方案审核、成果终审
- **尚书省**：执行调度 - 调度六部、汇总成果

### 执行层六部
- **吏部**：人事与绩效管理
- **户部**：数据与资源管理
- **礼部**：文档与沟通协同
- **兵部**：攻坚与专项执行
- **刑部**：合规与纠错风控
- **工部**：技术与工程实现

### 流程流转
```
用户任务 → 中书省制定方案 → 门下省审核 → 尚书省执行 → 门下省终审 → 交付
            ↑_______________| 驳回重写 |___________| 终审驳回
```

## 故障排查

### 问题1：Ollama连接失败
**错误信息**：
```
ollama._types.ResponseError: (status code: 502)
```

**解决方案**：
1. 确认Ollama已安装并运行
2. 检查模型是否已下载：`ollama list`
3. 重新启动Ollama服务

### 问题2：ModuleNotFoundError
**错误信息**：
```
ModuleNotFoundError: No module named 'langchain_ollama'
```

**解决方案**：
1. 确认在虚拟环境中
2. 重新安装依赖：`venv\Scripts\pip.exe install langchain langgraph langchain-ollama`

### 问题3：中文乱码
**解决方案**：
设置终端编码：
```powershell
[Console]::OutputEncoding = [System.Text.Encoding]::UTF8
```
